# Burmese Openworld — Beta (Sprint 0) Specification

This document summarizes the Beta scope for the project and the Sprint‑0 deliverables that were just added to the feature/beta branch.

Beta Goal (high level)
- Expand MVP into a playable Beta with: an overworld travel map, towns (shop/inn/recruit), party system, save/load, multi-unit battles integrated with overworld encounters, and Burmese+English localization stubs.

Sprint 0 (initial commit contents)
- Data models (unit, item) as JSON schemas
- Overworld scene stub (node graph + travel UI stub)
- Town scene template (shop/recruit/inn stubs)
- Save/load skeleton (scripts/save_system.gd)
- Localization CSV stubs (en/mm)
- Tasks and TODO list for upcoming sprints

Milestones & next steps
1. Sprint 1: implement overworld travel + encounter spawning (2 weeks)
2. Sprint 2: town systems & party roster (2 weeks)
3. Sprint 3: battle-party integration & rewards (2 weeks)

Branch: feature/beta
