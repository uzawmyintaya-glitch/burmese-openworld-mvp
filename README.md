# Burmese Openworld MVP

Godot 2D MVP scaffold (pixel art placeholders) for an offline Android game inspired by Mount & Blade style mechanics. Target: Android 7+ (API 24+). Contains a minimal overworld, a battle scene stub, Myanmar+English UI samples, and export notes.

Contents:
- scenes/
- scripts/
- assets/ (placeholders and instructions)
- android/README-android.md (export notes)

How to open:
1. Install Godot 4.1+ (recommended) or Godot 3.5 LTS.
2. Clone this repo and open it in Godot.

Notes:
- This scaffold contains code and scene stubs. Add real pixel art, music OGG, and fonts (Noto Sans Myanmar) in the assets/ directory before export.
- See android/README-android.md for Android export instructions.
