Battle prototype:

Controls:
- Tap left/right half of the screen to move the player a small step.
- Click/tap the enemy to deal damage (simple attack).
- Enemy AI will approach and attack automatically.

How to run:
1) Open scenes/battle.tscn in Godot and run the scene.
2) Replace placeholder SVG assets with proper sprites in assets/ if you want visuals.

Notes:
- This is a simple prototype for testing combat flow. It uses scripts/unit.gd for both player and enemy logic and scripts/battle.gd for scene management.
- You can expand player input, add animations, attack animations, damage effects, and a better UI for mobile (on-screen buttons).
