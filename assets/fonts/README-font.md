# Font install instructions

This project does not include the Noto Sans Myanmar TTF due to font file size and licensing considerations.

To add the Myanmar font for UI:
1) Download Noto Sans Myanmar from Google Fonts:
   https://fonts.google.com/noto/specimen/Noto+Sans+Myanmar
2) Place the TTF file at: assets/fonts/NotoSansMyanmar-Regular.ttf
3) In Godot, select your Label or Control node -> Custom Font -> DynamicFont -> Load the TTF path above.

Alternatively, you may use any Myanmar font you have a license for. Keep the font file under 5-10 MB to save build size.
