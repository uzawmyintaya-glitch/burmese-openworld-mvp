This folder contains placeholder asset instructions.

Steps to add real assets before export:
1) Pixel art sprites/tiles: put PNG files in this folder. Recommended sizes: 16x16, 32x32, 64x64 tiles.
2) Fonts: download Noto Sans Myanmar (https://fonts.google.com/noto/specimen/Noto+Sans+Myanmar) and place the TTF in assets/fonts/
3) Music: add OGG files (loopable) to assets/audio/ e.g., music_loop.ogg. Use OGG Vorbis, 64-96 kbps for short loops.
4) Replace the placeholder labels or link fonts in scenes.

Optional: add a small sprite png named `pixel_placeholder.png` for quick testing.
