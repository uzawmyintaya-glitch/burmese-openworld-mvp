# Overworld audio placeholders

This folder is for beta-era audio assets. Add these files to enable background music and SFX in the overworld:

- assets/audio/overworld_loop.ogg  -> ambient loop for overworld (recommended 44.1kHz, 64kbps)
- assets/audio/encounter.ogg      -> short tension sting for encounter trigger

If not present, the game will continue using synthesized SFX fallback for battle and will be silent for overworld music.
